# 数学分析讲义 · 交互学习（第 1–3 章）

依据 **程艺、陈卿、李平《数学分析讲义》第一册** 制作的可交互定理—题目索引。支持电脑、平板和手机浏览器。

## 在平板上使用（推荐）

1. 双击本目录里的 **`启动网站.bat`**。
2. 电脑会自动打开“在平板上打开”页面，上面有二维码和地址，例如：
   `http://10.15.26.198:8080/`
3. 让平板连接**与电脑相同的 Wi-Fi**，用相机扫描二维码即可。
4. 在平板浏览器菜单中选择“添加到主屏幕”，之后可以像 App 一样打开。

> 网站运行期间请保持命令行窗口开启；关闭窗口或按 `Ctrl+C` 即停止。
> 电脑重启、切换 Wi-Fi 后 IP 可能变化，重新双击 `启动网站.bat` 即可，二维码会自动更新。

### 如果平板打不开

- 确认电脑和平板在同一个 Wi-Fi，且没有连接不同的访客网络。
- 学校/单位 Wi-Fi 可能开启“客户端隔离”，设备之间不能互访。此时可以：
  - 用电脑开启 **移动热点**，平板连接该热点，然后重新运行 `启动网站.bat`；
  - 或让我帮你部署到公网（需要你提供可用的托管方式/账号）。
- 防火墙：本机已有 `python.exe` 的入站放行规则，一般无需处理；如果仍被拦截，右键 `启动网站.bat` → **以管理员身份运行**。

### 不用启动脚本时

在本目录运行：

```bash
python -m http.server 8080 --bind 0.0.0.0
```

电脑访问 `http://localhost:8080/`，平板访问 `http://电脑局域网IP:8080/`。

双击 `index.html` 即可，无需联网、无需服务器。

## 主要功能

- **章节目录**：按教材顺序跳转，记录已访问小节。
- **定理索引**：按类型（定义/定理/推论/引理）、章节筛选，支持关键词搜索。
- **题目索引**：按例题/习题、章节、小节、难度筛选，支持关键词搜索。
- **双搜索框**：顶部“定理”“题目”两个独立搜索框，实时下拉预览，回车查看全部结果。
- **图文对照**：每条规定/定理/题目都保留教材原页裁图，点击可放大；平板上支持双指缩放和拖动；跨页条目显示多张原图。
- **双向关联**：定理详情页列出“可应对的题目”；题目详情页列出“涉及的定理”。
- **知识图谱**：定理与题目的二部图，可拖拽、缩放、点击节点；支持按章节筛选和单点聚焦。
- **收藏与深浅色**：本地收藏、最近浏览、深浅色切换。
- **教材原文**：详情页可直接打开对应 PDF 页码。
- **平板适配**：触屏大按钮、横竖屏响应式布局、可添加到主屏幕（PWA manifest）。
